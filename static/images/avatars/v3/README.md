# v3 default faces

The faces the LangX v3 app gives a profile with no photo, used for the
demonstration people in the site's phones (src/lib/components/phone/people.ts).
They were exported from the app's master avatar sheet as flat SVGs: the soft
shape behind the head and the figure, on the ground the avatar board assigned,
with every shared part inlined so each file stands alone.
